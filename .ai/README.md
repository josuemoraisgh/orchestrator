# Orchestrator project workspace

- `specs/` contains the product requirements and acceptance criteria for this
  generic VS Code production orchestrator.
- `skills/` contains the generic procedures used by its agent.
- `orchestrator.json` belongs to projects initialized by the extension; it is
  not the extension's release configuration.

Cross-session memory and handoffs are managed by ai-memory when its setup is
available. Do not use archived QEMU investigation notes as active instructions.
